<h1>Decisions</h1>
Used Vite + React for fast development<br>
Created components folder (Header, Navbar, Footer etc) for clean structure<br>
Created pages folder to organize routing-based pages<br>
Used React Icons & FontAwesome CDN for icons<br>
Used .gitignore to ignore node_modules<br>
Followed modular component-based structure<br>
